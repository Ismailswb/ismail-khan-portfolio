# Ismail Khan — Full-Stack Software Engineer Portfolio

Premium personal portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — run ESLint

## Configuration

1. Update LinkedIn and GitHub URLs in `src/data/site.ts`
2. Set `NEXT_PUBLIC_SITE_URL` in `.env.local` (see `.env.example`)
3. Add your CV PDF to `public/Ismail-Khan-Full-Stack-Software-Engineer-CV.pdf`
4. Add project screenshots under `public/images/projects/`
5. Optionally set `graduationYear` in `src/data/experience.ts`
